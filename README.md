# 视频抓取器 - 无水印视频下载工具

一站式视频抓取工具，支持微信视频号、抖音、小红书无水印视频下载。

## ✨ 功能特点

- 🎬 **微信视频号** - 支持视频号视频抓取
- 🎵 **抖音** - 支持抖音短视频无水印下载
- 📕 **小红书** - 支持小红书视频笔记下载
- 🚫 **无水印** - 去除平台水印，获取原始画质
- 🌐 **在线使用** - Web界面，随时随地使用
- 📱 **响应式设计** - 支持手机和电脑访问

## 🚀 支持平台

| 平台 | 状态 | 说明 |
|------|------|------|
| 微信视频号 | ✅ | 支持分享链接抓取 |
| 抖音 | ✅ | 支持分享链接，无水印下载 |
| 小红书 | ✅ | 支持视频笔记下载 |

## 📦 本地部署

### 1. 安装依赖

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. 启动服务

```bash
python app.py
```

### 3. 访问

打开浏览器访问 http://localhost:8088

## 🌐 Render 部署

项目已配置 Render 部署，直接连接 GitHub 即可自动部署。

## 📖 使用方法

### 微信视频号
1. 在微信中打开视频号
2. 点击分享 → 复制链接
3. 粘贴到输入框，选择"微信视频号"
4. 点击"抓取视频"

### 抖音
1. 打开抖音 App
2. 点击分享 → 复制链接
3. 粘贴到输入框，选择"抖音"
4. 点击"抓取视频"

### 小红书
1. 打开小红书 App


2. 点击笔记右上角分享 → 复制链接
3. 粘贴到输入框，选择"小红书"
4. 点击"抓取视频"
